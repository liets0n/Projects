The objective is to get three circles or three crosses in a row, either horizontally, vertically or diagonally, and at the same time, when possible, prevent the opponent from winning on the next move. When a player conquers the objective, it is customary to cross out the three symbols.

## <span id="installation">:man_technologist: Quick Start</span>

To use the website on your local machine follow the steps below:

Cloning the Repository:

```sh
git clone git@github.com:username/Tic_Tac_Toe.git
```

Accessing the project folder:

```sh
cd Tic_Tac_Toe
```
Compiling:

```sh
gcc Tic-Tac-Toe.c -o game
```

execute:

```sh
./game
```
